# /wpw:exp

记录经验 / 踩坑 / 最佳实践。

## 执行流程

### 1. 门槛判断（5 问全过才记录）

- 是否有可复用的经验？
- 是否踩了值得记录的坑？
- 是否有偏离常规的最佳实践？
- 是否影响后续需求？
- 是否无法从代码直接推断？

未全过则不记录，避免噪声。

### 2. 提炼原始轨迹

从对话与改动中提炼经验：背景、问题、解决、结论、适用场景。

### 3. 按模板落盘

写入 `wpw/knowledge/experiences/<主题>.md`，结构：

```markdown
# 经验：<主题>
## 背景
## 问题
## 解决方案
## 结论与建议
## 适用场景
```

### 4. 自检

用 `@Humanizer-zh` 去机器腔，输出落盘确认。
