## ADDED Requirements

### Requirement: 语法骨架抽取
对代码类节点执行信息过滤时，系统 SHALL 保留元素名称、函数签名、入参出参类型、核心注解、接口定义；剔除函数实现体、循环逻辑、异常处理、日志代码、冗余注释。

#### Scenario: 函数节点骨架抽取
- **WHEN** 对一个 TypeScript 函数节点执行骨架抽取
- **THEN** 输出保留函数名、参数列表及类型、返回值类型、JSDoc 核心注解
- **AND** 剔除函数体实现、内部变量声明、循环与条件分支、日志语句

#### Scenario: 类节点骨架抽取
- **WHEN** 对一个类节点执行骨架抽取
- **THEN** 输出保留类名、继承关系、公共方法签名、属性声明与类型
- **AND** 剔除方法体内部实现

### Requirement: 层级符号化序列化
系统 SHALL 按照 L1→L2→L3→L4 的层级顺序，以缩进格式输出子图内容，用标准化符号表达从属与依赖关系。

#### Scenario: 子图层级化输出
- **WHEN** 对一个包含需求-模块-文件-函数的子图执行序列化
- **THEN** 输出按 L1→L2→L3→L4 缩进排列
- **AND** 使用 `⊃` 表示包含关系，`→` 表示调用/依赖关系，`⇄` 表示业务映射关系
- **AND** 输出末尾附带 Token 统计与压缩率信息

#### Scenario: 输出符号说明
- **WHEN** 执行序列化输出
- **THEN** 输出头部或尾部包含符号速查表
- **AND** 说明各符号的含义

### Requirement: 分级粒度控制
系统 SHALL 根据节点与锚点的距离分级输出信息密度：核心锚点最详细，一级依赖次之，二级及以上依赖最精简。

#### Scenario: 核心锚点完整输出
- **WHEN** 节点为锚点本身（距离=0）
- **THEN** 输出完整签名 + 核心属性 + 关键注释

#### Scenario: 一级依赖标准输出
- **WHEN** 节点为锚点的一级依赖（距离=1）
- **THEN** 输出名称 + 签名 + 入参出参类型

#### Scenario: 二级及以上依赖精简输出
- **WHEN** 节点与锚点距离 ≥ 2
- **THEN** 仅保留节点名称与类型

### Requirement: 三档压缩等级
系统 SHALL 支持 `loose`、`standard`、`extreme` 三档压缩等级，由配置文件统一控制。

#### Scenario: loose 宽松模式
- **WHEN** 配置压缩等级为 `loose`
- **THEN** 保留完整注释与更多细节，压缩率最低
- **AND** 信息完整度最高，Token 消耗最多

#### Scenario: standard 标准模式
- **WHEN** 配置压缩等级为 `standard`（默认值）
- **THEN** 平衡信息完整度与 Token 体积，适用于大多数场景

#### Scenario: extreme 极致模式
- **WHEN** 配置压缩等级为 `extreme`
- **THEN** 仅保留核心契约标识（名称、签名、类型），最大化压缩
- **AND** Token 消耗最少，信息密度最高
