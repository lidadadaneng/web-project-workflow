## Purpose

子图裁剪能力。基于锚点集合通过加权双向 BFS 生成最小连通依赖子图，支持节点上限裁剪与 Token 预算约束。

## Requirements

### Requirement: 多锚点子图生成
系统 SHALL 支持基于锚点节点集合，通过加权双向 BFS 广度优先搜索生成最小连通依赖子图。

#### Scenario: 单锚点子图扩展
- **WHEN** 传入 1 个锚点节点，最大深度为 3，最小权重为 0.7，节点上限为 50
- **THEN** 返回以该锚点为中心、深度 ≤ 3、边权重 ≥ 0.7 的连通子图
- **AND** 子图节点数 ≤ 50

#### Scenario: 多锚点子图合并
- **WHEN** 传入 3 个锚点节点，执行子图生成
- **THEN** 合并三个锚点各自扩展的子图，节点与边去重
- **AND** 形成连通子图（若锚点之间存在连通路径）

#### Scenario: 节点数超出上限裁剪
- **WHEN** 子图扩展后节点数超出上限
- **THEN** 按「语义分 × 0.6 + 结构重要度 × 0.4」综合得分排序，裁剪弱相关节点
- **AND** 最终节点数 ≤ 上限值

### Requirement: Token 预算约束裁剪
系统 SHALL 支持传入最大 Token 预算，自动调整裁剪粒度，保证最终压缩后的上下文文本不超出 Token 限制。

#### Scenario: Token 预算内生成子图
- **WHEN** 传入锚点集合与最大 Token 预算 8000
- **THEN** 系统通过调整深度、权重阈值与节点上限，迭代裁剪子图
- **AND** 最终压缩后的上下文文本 Token 数 ≤ 预算值
- **AND** 尽可能保留核心锚点与一级依赖

#### Scenario: Token 预算过小
- **WHEN** 传入的 Token 预算过小（如 500），不足以容纳核心锚点
- **THEN** 系统以极致压缩模式输出核心锚点的最小信息
- **AND** 输出警告提示预算不足

### Requirement: 双向 BFS 权重过滤
子图扩展 SHALL 仅保留权重大于阈值的依赖关系，防止弱关联边导致子图无限制扩散。

#### Scenario: 低权重边被剪枝
- **WHEN** 设置最小权重阈值为 0.8，某条 import 边权重为 0.75
- **THEN** 该边不参与子图扩展遍历
- **AND** 通过该边连接的节点不出现在子图中（除非有其他高权重路径可达）

### Requirement: 结构重要度计算
系统 SHALL 在节点裁剪时计算结构重要度，综合语义分与结构重要度决定裁剪优先级。

#### Scenario: 高结构重要度节点优先保留
- **WHEN** 子图需要裁剪，某节点被多条高权重边指向
- **THEN** 该节点的结构重要度得分较高
- **AND** 在综合排序中优先保留
