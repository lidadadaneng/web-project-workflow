# 订单统计分析

## Purpose
按状态分组或按时间统计已支付订单

## Requirements

### Requirement: 订单统计分析
系统应支持订单统计分析。

#### Scenario: existing implementation
- **WHEN** 用户执行相关操作
- **THEN** 系统按当前项目实现处理

### Requirement: 订单 status 与 group/value 联合定位
系统应支持订单 status 与 group/value 联合定位。

#### Scenario: existing implementation
- **WHEN** 用户执行相关操作
- **THEN** 系统按当前项目实现处理
