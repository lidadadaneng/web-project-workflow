# 用户密码重置

## Purpose
忘记密码后恢复默认密码

## Requirements

### Requirement: 用户密码重置
系统应支持用户密码重置。

#### Scenario: existing implementation
- **WHEN** 用户执行相关操作
- **THEN** 系统按当前项目实现处理

### Requirement: 重置密码与用户更新联合定位
系统应支持重置密码与用户更新联合定位。

#### Scenario: existing implementation
- **WHEN** 用户执行相关操作
- **THEN** 系统按当前项目实现处理
