大语言模型已从代码补全扩展到需求分析、设计、计划、测试和实现等软件工程活动，但在持续演化的复杂项目中，AI 编程智能体仍面临项目知识分散、业务语义与代码结构脱节以及上下文重复获取等问题。为此，本文提出面向 AI 辅助开发的图谱驱动上下文工程方法。该方法以规格驱动开发流程为基础，利用三段式契约和状态留痕约束各阶段的输入、处理与输出；以 Spec 为知识演化单元、Capability 为业务语义锚点，构建 C-L1-L2-L3 能力—代码双层知识模型，并通过 business_map 关联业务能力与模块、文件和函数；在任务执行时采用锚点选择、加权双向 BFS、代码骨架抽取和 Token 预算控制生成结构化上下文，并在需求变更后增量更新项目知识。本文实现 wpw 工具，并以美食推荐系统为载体，从开发成本、检索定位、回答质量和上下文效率等方面开展验证。实验结果表明，在本文项目和实验条件范围内，图谱增强检索能够改善相关代码的定位效果，结构化上下文生成能够减少冗余输入，二者共同降低了 AI 辅助开发中的模型资源消耗。

关键词：大语言模型；上下文工程；AI辅助软件开发；代码知识图谱；美食推荐系统

## ABSTRACT

Large language models have extended AI-assisted software development beyond code completion to requirements analysis, design, planning, testing, and implementation. In structurally complex and continuously evolving projects, however, AI coding agents still face fragmented project knowledge, weak links between business semantics and code structure, and repeated context acquisition. This thesis proposes a graph-driven context engineering method for AI-assisted software development. Built on a specification-driven development workflow, the method uses three-part contracts and state traces to constrain the inputs, processing, and outputs of each stage. It treats a Spec as the unit of knowledge evolution and a Capability as the semantic anchor between business intent and implementation, forming a C-L1-L2-L3 capability-code knowledge model in which business_map edges connect capabilities to modules, files, and functions. During task execution, anchor selection, confidence-weighted bidirectional breadth-first search, code-skeleton extraction, and token-budget control produce structured task context; after a requirement change, the project knowledge is updated incrementally. The method is implemented in the wpw tool and evaluated using a large language model-based food recommendation system in terms of development cost, code retrieval, answer quality, and context efficiency. The results indicate that, within the project and experimental conditions examined here, graph-enhanced retrieval improves the localization of relevant code, while structured context generation removes redundant input; together, these mechanisms reduce the model resources required for AI-assisted software development.

Key Words: Large Language Models; Context Engineering; AI-Assisted Software Development; Code Knowledge Graph; Food Recommendation System
