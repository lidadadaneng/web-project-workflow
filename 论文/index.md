# 面向 Web 项目的 AI 辅助开发工作流构建及知识图谱驱动上下文优化方法研究

> 本文件为论文**结构大纲**。各章正文写入独立文件（`1.绪论.md`、`2.相关理论.md`……），本大纲仅保留章节骨架与写作要点；各章详细草稿见 `index.填充版备份.md`。
>
> 验证环节以"美食推荐系统（vue + springboot）"为测试项目，对比 vibe coding、OpenSpec、Superpowers、wpw 四种方式，辅以消融实验分离工作流、知识图谱与上下文压缩的贡献。

## ABSTRACT

- 研究背景：LLM 辅助开发已拓展至多个软件工程活动，但面临流程覆盖、过程可控性与上下文效率挑战。
- 研究内容（三个创新点）：① 面向 AI Agent 的确定性开发工作流；② 能力-代码双层知识图谱（C+L1/L2/L3）；③ 图谱驱动的任务上下文压缩方法。
- 系统实现：CLI 层（TypeScript）+ AI 层（Claude Code Skill，14 个 /wpw 命令）+ 文件系统层；多语言源码解析、本地 Embedding、零数据库。
- 实验验证：四方案对比 + 消融实验（图谱/压缩/工作流贡献分离）。
- 关键词（英）：AI-Assisted Software Development；Agent Workflow；Code Knowledge Graph；Context Compression；Spec-Driven Development；Large Language Model
