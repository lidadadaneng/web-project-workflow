\begin{ChineseAbstract}
随着大语言模型能力的快速提升，AI辅助软件开发已从代码补全拓展到需求分析、设计、计划、测试与实现等软件工程全过程。然而，在复杂软件项目开发中，现有AI编程智能体面临上下文不足、项目知识割裂与流程不可控三大挑战：长上下文带来高成本与“中间丢失”问题，文档、代码与规则等项目知识缺乏统一组织，模型输出的非确定性与工程流程的确定性要求存在矛盾。针对上述问题，本文提出面向AI辅助开发的上下文工程方法。首先，构建覆盖需求、设计、计划、测试、实现全过程的上下文工程框架，通过三段式契约与状态留痕机制约束AI智能体行为；其次，提出面向软件项目知识持续利用的双层知识组织模型，以能力知识层与代码结构层的统一关联，解决文档、代码与规则割裂的问题；再次，提出图谱驱动的任务级上下文生成方法，通过检索、子图裁剪、骨架抽取与压缩生成，在有限Token预算内为开发任务提供高相关性的结构化上下文。在此基础上，本文实现了承载上述方法的wpw工具，并以基于大模型的美食推荐系统为实验载体，设计了包含四种AI辅助开发方式受控对比与三组机制消融的工程实验，从开发成本、系统实现质量、上下文效率与流程可控性等维度评估方法效果。实验结果表明，上下文工程方法中的流程约束、知识组织与上下文生成机制能够有效提升AI辅助开发的上下文质量与过程可控性。
\ChineseKeywords{大语言模型；上下文工程；AI辅助软件开发；代码知识图谱；美食推荐系统}
\end{ChineseAbstract}

\begin{EnglishAbstract}
With the rapid advancement of large language models (LLMs), AI-assisted software development has expanded from code completion to the entire software engineering process, including requirement analysis, design, planning, testing, and implementation. However, when developing complex software projects, existing AI coding agents face three major challenges: insufficient context, fragmented project knowledge, and uncontrollable processes. Long contexts incur high costs and suffer from the lost-in-the-middle problem; documents, code, and rules lack unified organization; and the non-determinism of model outputs conflicts with the determinism required by engineering workflows. To address these problems, this thesis proposes a context engineering approach for AI-assisted software development. First, a context engineering framework covering the whole process of requirement, design, planning, testing, and implementation is constructed, in which three-stage contracts and state persistence constrain the behavior of AI agents. Second, a two-layer knowledge organization model for the continuous utilization of software project knowledge is proposed, which unifies a capability knowledge layer with a code structure layer to resolve the fragmentation among documents, code, and rules. Third, a graph-driven task-level context generation method is proposed, which provides highly relevant structured context within a limited token budget through retrieval, subgraph pruning, skeleton extraction, and compressed generation. On this basis, the wpw tool is implemented as the carrier of the proposed approach, and a controlled engineering experiment is designed with an LLM-based food recommendation system as the experimental carrier, comparing four AI-assisted development approaches and conducting three ablation studies. The results are evaluated in terms of development cost, system implementation quality, context efficiency, and process controllability, demonstrating that the process constraint, knowledge organization, and context generation mechanisms effectively improve the context quality and process controllability of AI-assisted software development.
\EnglishKeywords{Large Language Model; Context Engineering; AI-Assisted Software Development; Code Knowledge Graph; Food Recommendation System}
\end{EnglishAbstract}
